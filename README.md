# Misaka 弹幕 (service.misaka.danmaku)

适用于 [misaka_danmu_server](https://github.com/l429609201/misaka_danmu_server) 的 Kodi 插件(Kodi 19+ / CoreELEC 19+)。
对接其弹弹play 兼容接口: `/api/v1/{token}/match`、`/search/episodes`、`/comment/{episodeId}`。

## 安装
Kodi → 设置 → 插件 → 从 zip 文件安装 → 选择 `service.misaka.danmaku.zip`。
然后在插件设置里填:
- 服务器地址(如 `http://192.168.1.2:7768`,端口以你的部署为准)
- Token(Web 管理界面 → 弹幕 API 令牌)

## 两种渲染方式(设置 → 显示 → 渲染方式)
| | 弹幕层(默认) | ASS 外挂字幕 |
|---|---|---|
| 原理 | 往全屏视频窗口加文字控件,GUI 动画滚动 | 生成 .ass,当作字幕加载 |
| 外挂字幕 | 完全独立,正常使用 | 自动与 .srt/.ass 合并成一个字幕文件 |
| 性能 | 同屏上限可调(默认 30),低端盒子建议 ≤30 | 最好,几乎无开销 |
| 暂停/拖动 | 暂停时清屏,拖动后重新定位 | 由播放器处理,最准确 |

## 打开自建 UI 面板
播放时 Kodi 无法进入插件菜单,需要绑定一个按键。新建 `userdata/keymaps/misaka.xml`:

```xml
<keymap>
  <FullscreenVideo>
    <keyboard>
      <d>RunScript(service.misaka.danmaku,panel)</d>
    </keyboard>
  </FullscreenVideo>
</keymap>
```
遥控器按键请按你的遥控器键名替换(可用 Kodi 的 Keymap Editor 插件)。
面板功能:选择匹配结果 / 搜索番剧 / 弹幕开关 / 切换渲染方式 / 加载外挂字幕 / 时间偏移 ±0.5s / 设置。

## 匹配逻辑
1. 播放开始后读取 Kodi 的视频信息(剧名、季、集),优先使用**上次手动选过的番剧**(按"剧名|季"记忆),直接取对应集;
2. 否则用 `剧名 S01E03` 调用 `/match`,`isMatched` 为真则自动加载;
3. 否则回退到 `/search/episodes`;候选多于一个时弹出选择窗口。你选过一次后,同一部剧后续的集数会自动匹配。
4. 直播(pvr://)和短于设定时长(默认 3 分钟)的视频不会触发匹配。

## 行为说明
- **时间偏移**:正数 = 弹幕延后,负数 = 提前(两种渲染方式一致)。面板里 ±0.5 秒按钮即时生效。
- **暂停 / 拖动 / 快进后**:弹幕层会把此刻本该在屏幕上的弹幕按正确位置补回,不会出现"空屏"。
- **非全屏视频窗口**(如在菜单里)弹幕层自动隐藏。
- **弹幕缓存**:同一集的弹幕在本地缓存 12 小时,重复播放不再请求服务器。
- **刷屏过滤**:3 秒内重复的相同弹幕会合并(可在设置关闭)。
- **ASS 模式**:弹幕在下层、字幕在上层;每次重新生成用新文件名,避免 Kodi 缓存旧字幕。
  从 ASS 切回弹幕层时:有外挂字幕则恢复它,没有则关闭字幕(Kodi 无法单独卸载一条字幕)。
- 设置里有"测试服务器连接"按钮,可检查地址和 Token。

## 已知限制
  **没法验证**的是真实皮肤下的渲染效果和 GUI 动画帧率。请先小范围测试。
- 弹幕层依赖向全屏视频窗口(ID 12005)添加控件,不同皮肤/Kodi 版本表现可能略有差异;看不到弹幕时改用 ASS 模式。
- 文字宽度按字号估算(中文=字号,英文≈0.55 倍),控件宽度已留余量避免被截断,但轨道间距可能略有偏差。字号和字体名可在设置里调整;
  字体名必须是当前皮肤里存在的字体(默认 font13)。
- ASS 的字体由 Kodi 的字幕字体设置决定。
- 高级弹幕(模式 7)被忽略;仅支持 `.srt` / `.ass` 外挂字幕的合并(`.ssa`/`.sub` 只能单独加载,不合并)。
- Emby 串流的远程字幕没法用文件浏览器选择,请使用本地或网络共享里的字幕文件。
